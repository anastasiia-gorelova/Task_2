# API-тесты Stellar Burgers

В каталоге `tests` находятся пять тестовых классов для регистрации, входа, изменения профиля, создания заказа и получения заказов пользователя. Тесты работают с учебным стендом `https://qa-stellarburgers.education-services.ru`. Каждый тест создаёт нужные ему данные отдельно. После теста фикстура удаляет зарегистрированные им аккаунты. Удаление заказов в API не предусмотрено.

## Запуск и отчёт

Для построения HTML-отчёта требуется Allure CLI версии 2 с поддержкой `--single-file`.

```sh
python3 -m pip install -r requirements.txt
python3 -m pytest -q --alluredir=allure-results --clean-alluredir
allure generate allure-results --clean --single-file -o allure-report
```

Отчёт открывается в браузере из файла `allure-report/index.html`. Команду генерации можно выполнить и после прогона с упавшими тестами.

## Результат проверки

Стенд ответил HTTP 200 на создание заказа с ингредиентами без авторизации. На странице 5 документации оформление заказа доступно только авторизованным пользователям. Тест ожидает отказ в доступе (HTTP 401), поэтому расхождение видно в отчёте.
